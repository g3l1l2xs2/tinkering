# API shape tinkering

Some rough notes on designing a small JSON API.

- Prefer explicit `data` envelope? Maybe not for internal endpoints.
- Use `errors` array with `code`, `title`, `detail`.
- Pagination via `page` and `per_page`, return `total_count` only when requested.
- Idempotency key header: `Idempotency-Key` for POSTs.
- Try OpenAPI 3.1 for docs, but keep it lightweight.
